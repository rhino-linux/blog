We are happy to announce the release of our 2026.1 snapshot images! Since late 2025, our focus has primarily been centered around our partnership with the UBports team and bringing Lomiri to a wider range of devices.

## Lomiri on x86_64 & ARM64 ISOs

Following from the progress we previously shared in 2025, we are happy to announce that we have shipped our generic ISO images (x86_64/ARM64) for Lomiri. This work has built upon our continued and increasing collaboration with the UBPorts team to improve and refine the Lomiri experience, as well as making Lomiri more accessible beyond mobile hardware.

Those installing Rhino Linux on standard x86_64 or ARM64 systems can now choose to experience Lomiri as their desktop environment of choice.

While Lomiri support on generic systems is still considered an evolving experience, we are excited by the progress made so far and are excited to continue working closely with the UBports team to provide improvements for Lomiri users on desktop and mobile.

## Pacstall

Pacstall recieved substantial updates during this release cycle. The Pacstall 6.4.x series adds:

- New `DNUM` and `CDNUM` internal variables.
- New `PACSTALL_XTRACEFD` and `PACSTALL_XTRACEFDLOG` environment variables.
- Exporting `KVER` to pre/post scripts.

As always, multiple bugs were squashed in Pacstall 6.4.x, as well as some internal cleanups and translation updates. The full changelog for Pacstall can be found on their [releases page](https://github.com/pacstall/pacstall/releases/tag/6.4.0).

## As well as...

- Kernel version `7.0.9-generic` ships by default on Generic ISO disk images.
- Kernel version `6.18.32-sunxi` ships by default on PinePhone & PineTab images.
- Kernel version `6.18.32-rockchip` ships by default on PinePhone Pro images.
- Kernel version `6.9.0-okpine` ships by default on PineTab2 images.
- Kernel version `7.0.0-raspi` ships by default on Raspberry Pi images.
